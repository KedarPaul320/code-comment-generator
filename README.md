# Code Comment Generator (Streamlit)

A Python/Streamlit port of the original Next.js "Code Comment" app. Paste
code or upload a file, pick a language, and get an AI-commented version
back, generated by a local Ollama model.

## Setup

1. Install and start [Ollama](https://ollama.com), then pull the model:
   ```bash
   ollama pull llama3
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the app:
   ```bash
   streamlit run app.py
   ```

The project is organized into:

- `app.py` — Streamlit entry point
- `ui/` — Streamlit interface and language mappings
- `services/` — prompt construction and Ollama API calls
- `config.py` — local settings ignored by Git
- `.streamlit/config.toml` — application colors, typography, and widget styling

Local settings can be placed in `config.py`; this file is ignored by Git and
will not be uploaded to GitHub. Start from `config.example.py`:

```bash
cp config.example.py config.py
```

By default it talks to Ollama at `http://localhost:11434`. To point it
elsewhere (a remote Ollama box, a different model), set env vars before
running:

```bash
export OLLAMA_URL="http://your-host:11434/api/generate"
export OLLAMA_MODEL="llama3:latest"
streamlit run app.py
```

## What's the same as the original

- Paste code or import a file
- Pick from the same 8 languages
- Same prompt sent to the model (block comments + inline comments)
- Same dark, editor-inspired feel via `st.code()`'s built-in dark theme

## What's different/improved

- **Configurable backend** — the Ollama URL/model are env vars, not hardcoded,
  so this isn't stuck to `localhost` the way the original API route was.
- **Timeout on the LLM call** — a stuck Ollama request no longer hangs forever.
- **Markdown fence stripped** — if the model wraps its reply in `` ```code``` ``,
  that wrapper is removed before display (the original showed it literally).
- **Syntax highlighting + copy button** — free from `st.code()`, no extra work.
- **Download button** — save the commented file with the right extension.
- **Language auto-detected** from an uploaded file's extension.
- **Length guard** — a 20,000-character cap on submitted code, with a live
  counter, so one huge paste can't turn into a huge, slow prompt.
- **Errors are logged**, not just swallowed into a generic message.

## Notes

This still requires Ollama running somewhere reachable — it's a straight
port of the original's local-LLM approach, not a switch to a hosted API.
If you'd rather call OpenAI/Anthropic/etc. instead, swap out `call_ollama()`
for a call to that provider's SDK; the rest of the app (UI, prompt,
fence-stripping, download) doesn't need to change.
